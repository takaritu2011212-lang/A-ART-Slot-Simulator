# 🎰 A+ART パチスロシミュレーター

A+ART方式のパチスロ機を完全仕様書に準拠して実装した、ブラウザで遊べるシミュレーターです。

## 📋 特徴

- ✅ **完全仕様書準拠** - A+ART完全仕様書・統合版に完全対応
- 🎮 **ゲーム性重視** - 実際のパチスロ機のシステムを完全再現
- 📊 **統計データ管理** - プレイ履歴やボーナス回数などを自動記録
- 🎨 **役示唆演出** - 色による成立役予告機能
- 💾 **データ永続化** - LocalStorageでプレイデータを自動保存
- 🌐 **ブラウザ対応** - URLをクリックするだけで遊べる

## 🎯 ゲームシステム概要

### 基本仕様
- **ゲーム単価**: 3枚掛け
- **基本構成**: 通常時 → ボーナス → ART Challenge → ART
- **ART初期G**: 60G
- **各設定対応**: 設定1～6

### ゲーム状態

| 状態 | 説明 |
|------|------|
| **通常時** | ボーナス抽選中。リプレイ～チャンス目を搭載 |
| **BIG** | 250枚獲得。終了後、ART Challenge or Episode Bonus |
| **REG** | 70枚獲得。終了後、設定別のART Challenge抽選 |
| **ART Challenge** | 5G。成功でARTストック獲得 |
| **ART** | 60G開始。上乗せ、高確、特殊ゾーン搭載 |
| **参戦ゾーン** | 10G。6種類のキャラクター別上乗せシステム |
| **Burst Mode** | 25G。ストック獲得で報酬に変換 |
| **Attack Time** | 3G。毎ゲーム確定上乗せ |
| **反転の刻** | ART残りG+1で継続。ボーナスで終了 |

## 🎨 役示唆システム

通常時の演出では、色によって成立役を予告します：

| 色 | 示唆役 |
|----|--------|
| ⚪ 白 | ハズレ |
| 🔵 青 | リプレイ |
| 🟡 黄 | 3枚ベル |
| 🟢 緑 | スイカ |
| 🩷 桃 | 弱チェリー |
| 🔴 赤 | 強チェリー |
| 🟣 紫 | チャンス目 |
| 🌈 虹 | 確定系・特殊 |

**重要**: 色は「期待度」ではなく「成立役予告」です！  
青示唆で強チェリーが出たら、それが「矛盾」＝チャンスです。

## 🎮 操作方法

### 基本流れ
1. **BET** → 3枚投入
2. **スタート** → リール回転
3. **停止1～3** → 左・中・右を順に停止
4. 成立役を確認 → 次ゲームへ

### 停止順について
- **必ず左第一停止**が決まりです
- その後、中 → 右 or 右 → 中 の2種類から選択
- 右第一停止・中第一停止はできません

## 📊 統計データ

ゲーム画面下部に以下の統計が表示されます：

| 項目 | 説明 |
|------|------|
| **総ゲーム数** | これまでのプレイゲーム数 |
| **総投入** | 投入した枚数合計 |
| **総払出** | 獲得した枚数合計 |
| **機械割** | 払出 ÷ 投入 × 100（%） |
| **BIG / REG / ART** | 各ボーナス・ART初回数 |
| **ART総G** | ART中の消化ゲーム数合計 |
| **平均ART** | 1回のART平均継続ゲーム数 |
| **参戦 / バースト** | 各特殊ゾーン発動回数 |
| **設定** | 現在の設定（1～6） |

### データ管理
- **自動保存**: LocalStorageに自動で保存
- **リセット**: 「データリセット」ボタンで履歴を全削除
- **設定変更**: ドロップダウンメニューで設定1～6を選択可能

## ⚙️ 設定別機械割

各設定でボーナス確率と期待値が異なります：

| 設定 | 機械割 | ボーナス合算 | 平均ART |
|------|--------|------------|--------|
| 1 | 96.78% | 1/199.7 | 201.1G |
| 2 | 97.62% | 1/199.7 | 204.3G |
| 3 | 99.41% | 1/198.0 | 212.8G |
| 4 | 101.53% | 1/194.9 | 218.0G |
| 5 | 104.30% | 1/190.9 | 229.9G |
| 6 | 107.24% | 1/188.1 | 231.6G |

設定6が最も出玉性能が高いです。

## 💡 ゲーム性のポイント

### 矛盾を楽しむ
- 青示唆（リプレイ予告）で強チェリーが出た → 矛盾＝チャンス！
- 予告と成立役が一致するかズレるか、毎ゲーム確認する楽しみ

### 小さな契機の連鎖
- ボーナス → ART Challenge成功 → Attack Time → ART開始
- ART中に高確獲得 → 参戦ゾーン → バースト → ストック
- 複数の小さな当選が積み重なってART継続

### 設定差の実感
- 設定1と設定6では約10%の機械割差
- 同じ設定でも確率的なズレあり
- 長期プレイで設定差が徐々に現れる
